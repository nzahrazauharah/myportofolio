# myPortofolio

A professional central hub and responsive personal portfolio website showcasing an integrated journey across academic backgrounds, large-scale administration, organizational leadership, and digital creation.

## Overview

**myPortofolio** is a centralized digital space developed to present my academic milestone, organizational leadership, technology-driven execution, and professional development. It acts as an optimization hub connecting various cross-disciplinary initiatives in EdTech, web development, and digital enterprise management.

## Key Indicators & Metrics

- **1,400+ Participants Supported:** Proven administrative scale through regional youth event execution.
- **4 Featured Digital Products:** Direct implementation of functional, interactive client-side web platforms.
- **3+ Core Leadership Roles:** Ongoing management in academic, institutional, and community sectors.

## Architecture & Sections

- **About Me:** Professional background, core methodology, and personal statement.
- **Education:** Mathematics Education baseline at Universitas Siliwangi and strategic academic roles.
- **Experience:** Operational data verification for organizational leadership and entrepreneurship.
- **Projects:** Selected functional web developments (*GalaxiaMath, Popibooth, Zauvarie*).
- **Certifications:** Verified professional credentials including **Gemini Certified Student** by Google for Education.
- **Skills & Languages:** Technical competencies (HTML/CSS/JS, Office/Workspace Suites) and linguistic proficiencies (English & Indonesian).

## Technology Stack & Deployment

- **Languages:** HTML5, CSS3, JavaScript (Vanilla ES6).
- **Architecture Style:** Component-driven structural layout compiled into a clean single-file entry deployment to ensure optimized client-side rendering speed, rapid loading times, and zero-server dependency.
- **Hosting Strategy:** Deployed natively via **GitHub Pages** for automated CI/CD and secure public access.
- **Methodology:** Developed using *Rapid Prototyping* mechanics, leveraging Google Gemini as an elite engineering co-pilot for code structuring and structural optimization.
